## 第 2 步：解压

1. 找到下载的 `campusnet-guard-windows.zip`
2. 右键 → **全部解压缩**
3. 选择解压到桌面或任意文件夹
4. 解压后会看到 `0-先看我-使用说明.txt` 和 `1-点我启动-校园网守护.exe`

## 第 3 步：双击运行

双击 `1-点我启动-校园网守护.exe`。

### 可能弹出的安全提示

**情况 1：蓝色窗口 "Windows 已保护你的电脑"**

当前版本暂未进行代码签名，因此 Windows SmartScreen 可能提示未知发布者。请只从官方 GitHub Releases 下载，并自行判断是否信任。

1. 点击 **"更多信息"**
2. 点击 **"仍要运行"**

**情况 2：黄色窗口 "未知发布者"**

同上，点击 **"仍要运行"**。

请只从官方 GitHub Releases 下载，并自行判断是否信任。

## 第 4 步：添加账号

1. 打开 GUI 的 **高级** 页
2. 点击 **添加账号**
3. 选择运营商：
   - 电信 → 选 **DX**
   - 移动 → 选 **YD**
   - 联通 → 选 **LT**
   - 校园网直连 → 选 **校园网**
4. 输入学号
5. 输入密码（输入时不会显示，这是正常的）
6. 点击 **保存并验证**

验证成功后会显示"登录成功"。

## 第 5 步：开启守护

1. 回到 **主页**
2. 点击 **开始守护**

程序会每 10 秒检测一次网络。如果断网，会自动重新认证。日志会显示：
- `[INFO] 网络正常` — 一切正常
- `[WARN] 断连` — 断网了，正在重连
- `[OK] 重连成功` — 已重新连上

## 第 6 步（可选）：开机自启动

1. 打开 **设置** 页
2. 勾选 **开机后自动运行并守护校园网**

以后电脑开机后会自动启动并进入守护模式，不需要手动操作。

## 出错时怎么办

1. **截图**：按键盘上的 `Print Screen` 键，然后粘贴到微信/QQ 发给帮你的人
2. **复制日志**：在 GUI 日志区域，选中文字 → 右键 → 复制
3. **运行诊断**：打开 `9-排障工具-不懂不用点.exe`，输入 `doctor`，把输出发给帮你的人

## 常见问题

**Q: 密码输入时看不到？**
A: 这是正常的。密码输入时不会显示任何字符，输入完按回车即可。

**Q: 提示"登录失败"？**
A: 检查运营商是否选对、学号密码是否正确。

**Q: 提示"认证服务器地址不对"？**
A: 示例认证地址是 `172.16.54.18`，实际以你学校/单位认证页为准。联系学校网络中心确认。

**Q: 开了代理、VPN 或 TUN 模式，需要先关掉吗？**
A: 不一定。程序会尽量让认证请求直连校园网认证服务器。如果仍然登录失败，打开 `9-排障工具-不懂不用点.exe` 运行 `doctor`，看"代理/VPN 兼容性"提示；普通用户可以先临时暂停代理/VPN/TUN 后重试。

**Q: 换电脑后密码不可用？**
A: 密码加密后绑定当前电脑，换电脑需要重新添加账号。
