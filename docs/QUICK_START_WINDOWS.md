# Windows 快速使用指南

写给完全不懂电脑的同学。

## 第 1 步：下载

### 主渠道：GitHub Releases

1. 打开 https://github.com/mi179/campusnet-guard/releases/latest
2. 找到 **Assets**（页面下方）
3. 点击 **cyber-lobster-windows.zip** 下载

### GitHub 下载慢怎么办

如果 GitHub 打不开或下载很慢：

1. **使用可信的 GitHub 代理**
   - 搜索 "GitHub 加速" 或 "GitHub 镜像"
   - 将下载链接中的 `https://github.com/` 替换为代理地址
   - ⚠️ 只使用可信的代理，不要用来路不明的下载链接

2. **让同学帮忙**
   - 让能访问 GitHub 的同学帮你下载
   - 通过微信/U盘/局域网传给你

3. **使用备用下载渠道**（计划中）
   - 项目计划提供 Cloudflare Pages 官方页面
   - 提供备用下载入口

> ⚠️ **安全提醒**：请只从 GitHub Releases 或官方页面下载，不要使用来路不明的 exe 文件，可能被篡改或捆绑病毒。

## 第 2 步：解压

1. 找到下载的 `cyber-lobster-windows.zip`
2. 右键 → **全部解压缩**
3. 选择解压到桌面或任意文件夹
4. 解压后会看到 `cyber-lobster-gui.exe` 和 `cyber-lobster-cli.exe`

## 第 3 步：双击运行

双击 `cyber-lobster-gui.exe`。

### 可能弹出的安全提示

**情况 1：蓝色窗口 "Windows 已保护你的电脑"**

这是因为程序没有购买代码签名证书（年费几千元，个人项目买不起）。

1. 点击 **"更多信息"**
2. 点击 **"仍要运行"**

**情况 2：黄色窗口 "未知发布者"**

同上，点击 **"仍要运行"**。

**这不是病毒**，只是 Windows 对没有签名证书的程序的正常提示。

## 第 4 步：添加账号

1. 打开 GUI 的 **高级** 页
2. 点击 **添加账号**
3. 选择运营商：
   - 电信 → 选 **DX**
   - 移动 → 选 **YD**
   - 联通 → 选 **LT**
   - 校园网直连 → 选 **校园网**
4. 输入学号
5. 输入密码（输入时不会显示，这是正常的）
6. 点击 **保存并验证**

验证成功后会显示"登录成功"。

## 第 5 步：开启守护

1. 回到 **主页**
2. 点击 **开始守护**

程序会每 10 秒检测一次网络。如果断网，会自动重新认证。日志会显示：
- `[INFO] 网络正常` — 一切正常
- `[WARN] 断连` — 断网了，正在重连
- `[OK] 重连成功` — 已重新连上

## 第 6 步（可选）：开机自启动

1. 打开 **设置** 页
2. 勾选 **开机后自动运行并守护校园网**

以后电脑开机后会自动启动并进入守护模式，不需要手动操作。

## 出错时怎么办

1. **截图**：按键盘上的 `Print Screen` 键，然后粘贴到微信/QQ 发给帮你的人
2. **复制日志**：在 GUI 日志区域，选中文字 → 右键 → 复制
3. **运行诊断**：打开 `cyber-lobster-cli.exe`，输入 `doctor`，把输出发给帮你的人

## 常见问题

**Q: 密码输入时看不到？**
A: 这是正常的。密码输入时不会显示任何字符，输入完按回车即可。

**Q: 提示"登录失败"？**
A: 检查运营商是否选对、学号密码是否正确。

**Q: 提示"认证服务器地址不对"？**
A: 默认是 `172.16.54.18`，不同学校可能不同。联系学校网络中心确认。

**Q: 换电脑后密码不可用？**
A: 密码加密后绑定当前电脑，换电脑需要重新添加账号。
