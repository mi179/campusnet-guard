✨ 特性

  • 自动认证 — 断网时自动重新登录校园网
  • 密码安全 — 密码本地加密保存，不上传、不明文

🚀 快速开始

Windows

  1. 下载 campusnet-guard-windows.zip
  2. 解压，双击 campusnet-guard-gui.exe
  3. 添加账号（运营商、学号、密码）
  4. 点击"开始守护"

首次运行可能触发 Windows SmartScreen，点击"更多信息" → "仍要运行"即可。

Linux

git clone https://github.com/mi179/campusnet-guard.git
cd campusnet-guard
bash scripts/linux/install.sh
source .venv/bin/activate
campusnet setup
campusnet start

❓ 常见问题

认证服务器地址是多少？

不同学校不同。示例 172.16.54.18，实际以你学校/单位认证页为准。

密码安全吗？

Windows 使用 DPAPI 保护密码，Linux 使用本地密钥保护密码；不会明文落盘，不会上传。

Windows 提示"未知发布者"？

当前版本暂未进行代码签名。请只从官方 GitHub Releases 下载，并自行判断是否信任。点击"更多信息" → "仍要运行"即可。

在线设备数量有限制？

这取决于学校网络策略，本工具无法改变。

支持 macOS 吗？

暂未验证，不作为当前支持平台。
